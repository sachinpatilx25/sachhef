# HefShine Recordings Downloader & Offline Player

A standalone web app to browse, download, and watch HefShine LMS class recordings offline with synchronized audio and screen video.

## Features
- **Combined Audio + Video**: Automatically merges teacher webcam/microphone audio and high-definition screen recordings into a single MP4 file.
- **One-Click Download All**: Queue and download all batch lectures in one click.
- **Offline HTML5 Video Player**: Watch downloaded classes with seeker and fullscreen support.
- **Clean Multi-User Login**: Supports any student login without hardcoded credentials.

## Quick Start
1. Run `start.bat` (or run `python server.py`).
2. The portal will automatically open in your browser at `http://localhost:8899`.
3. Sign in with your HefShine student credentials.
